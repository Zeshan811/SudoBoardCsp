# SudoBoardCsp

SudoBoardCsp is a Python-based project focused on solving Sudoku puzzles using Constraint Satisfaction Problem (CSP) techniques. The project demonstrates how artificial intelligence and backtracking algorithms can efficiently solve Sudoku boards.

## 🚀 Features
- Sudoku puzzle solver
- Constraint Satisfaction Problem (CSP) implementation
- Backtracking algorithm
- Efficient constraint checking
- Python notebook implementation
- AI problem-solving demonstration

## 🧠 How It Works

The solver treats Sudoku as a Constraint Satisfaction Problem where:

* Each empty cell is considered a variable
* Possible numbers are treated as domains
* Sudoku rules act as constraints
* Backtracking is used to search for valid solutions

The algorithm continuously checks constraints while filling cells to efficiently solve the puzzle.
